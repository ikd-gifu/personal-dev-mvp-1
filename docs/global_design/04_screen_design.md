| ---------- | ---------------------------- | ------- | ------- | ------------------------------------------------------------------------------------- |

## グローバル遷移・ナビ

* ロゴ

  * 画面左上に表示する。
  * クリックすると `/notes` のノート一覧へ遷移する。

* サイドバー

  * ログイン中は固定表示する。
  * `Notes`

    * `/notes` のノート一覧へ遷移する。
  * `Templates`

    * `/templates` のテンプレート一覧へ遷移する。
  * `My Notes`

    * `/my-notes` の自分のノート一覧へ遷移する。

* 右上ユーザーメニュー

  * ログイン中のみ表示する。
  * プロフィールアイコンをクリックするとドロップダウンを表示する。
  * `My Notes`

    * `/my-notes` へのショートカット。
  * `Logout`

    * ログアウト後、`/login` へリダイレクトする。

* 未ログイン時

  * サイドバーは表示しない。
  * `/login` のGoogleログイン画面のみアクセス可能とする。

* 初回ログイン成功時

  * `/notes` へリダイレクトする。

* エラー画面

  * 存在しないページは `/404` を表示する。
  * 権限がない場合は `/403` を表示する。
  * MVPでは簡易エラーページとする。

## 検索クエリ（MVP）

* ノート一覧

  * URL形式：`/notes?q=検索語&status=draft|publish&page=1`
  * 検索対象はタイトルのみ。
  * MVPではセクション本文の検索は実装しない。
  * `status` で `draft` または `publish` に絞り込む。
  * `page` でページ番号を指定する。

* テンプレート一覧

  * URL形式：`/templates?q=検索語&page=1`
  * 検索対象はテンプレート名のみ。
  * MVPでは項目名の検索は実装しない。
  * `page` でページ番号を指定する。

## 画面設計詳細

### ログイン AUTH-LOGIN

| 区分 | 項目／操作         | 説明                                          |
| -- | ------------- | ------------------------------------------- |
| 表示 | サービスロゴ        | 「Mini Notion」ロゴを表示する。クリックで `/notes` に戻ってもよい |
| 表示 | サブコピー         | 「設計メモを構造化して残すミニノートアプリ」などの簡単な説明を表示する         |
| 操作 | Googleログインボタン | OAuth認証を開始する。認証成功後に `/notes` へリダイレクトする      |

### ノート一覧 N-LIST

| 区分 | 項目／操作   | 説明                                  |
| -- | ------- | ----------------------------------- |
| 表示 | タイトル    | ノートのタイトル。クリックすると `/notes/:id` へ遷移する |
| 表示 | ステータス   | `Draft` または `Publish` を表示する         |
| 表示 | 更新日時    | `updatedAt` を表示し、更新日時の降順でソートする      |
| 操作 | 検索ボックス  | タイトルの部分一致検索を行う                      |
| 操作 | ステータスフィルタ | Draft／Publish で絞り込み |
| 操作 | 新規作成    | `/notes/new` へ遷移する                  |
| 操作 | ノートクリック | `/notes/:id` のノート詳細へ遷移する            |

### ノート詳細 N-DETAIL

| 区分 | 項目／操作      | 説明                                     |
| -- | ---------- | -------------------------------------- |
| 表示 | タイトル       | ノートタイトルを表示する                           |
| 表示 | 作成者／更新日時   | `Account.name` と `updatedAt` を表示する     |
| 表示 | 各セクション     | テンプレートに基づく内容を表示する                      |
| 表示 | ステータス      | Draft または Publish を表示する            |
| 操作 | 編集         | Ownerのみ表示する。`/notes/:id/edit` へ遷移する    |
| 操作 | 削除         | Ownerのみ操作可能。確認モーダル表示後に削除し、`/notes` へ戻る |
| 操作 | ステータス切り替え  | Ownerのみ操作可能。`Draft` と `Publish` を切り替える |
| 操作 | テンプレート名リンク | `/templates/:templateId` へ遷移する         |

* 表示するセクション例

  * Problem
  * 原因
  * 対策
  * Design
  * Verification
  * Next Steps

### ノート新規作成 N-NEW

| 区分 | 項目／操作    | 説明                               |
| -- | -------- | -------------------------------- |
| 入力 | タイトル     | 必須。ノートのタイトルを入力する                 |
| 入力 | テンプレート選択 | 必須。テンプレートを選択し、`templateId` を設定する |
| 入力 | 各セクション   | テンプレートに基づく項目を入力する。MVPでは文字列のみ     |
| 操作 | 保存       | ノート作成後、`/notes/:id` へ遷移する        |
| 操作 | キャンセル    | `/notes` へ遷移する                   |

### ノート編集 N-EDIT

| 区分 | 項目／操作     | 説明                                        |
| -- | --------- | ----------------------------------------- |
| 表示 | 現在のステータス  | `Draft` または `Publish` を表示する。Ownerのみ切り替え可能 |
| 入力 | タイトル      | 必須。既存タイトルを編集する                            |
| 入力 | 各セクション    | 既存内容を編集する。MVPでは文字列のみ                      |
| 操作 | ステータス切り替え | Ownerのみ操作可能。`Draft` と `Publish` を切り替える    |
| 操作 | 保存        | 更新後、`/notes/:id` へ遷移する                    |
| 操作 | 削除        | Ownerのみ操作可能。確認後に削除し、`/notes` へ遷移する        |
| 操作 | キャンセル     | `/notes/:id` へ戻る                          |

### テンプレート一覧 T-LIST

| 区分 | 項目／操作      | 説明                                    |
| -- | ---------- | ------------------------------------- |
| 表示 | テンプレート名    | 一覧表示する。クリックすると `/templates/:id` へ遷移する |
| 表示 | 作成者        | Ownerの `Account.name` を表示する           |
| 操作 | 検索ボックス     | テンプレート名の部分一致検索を行う                     |
| 操作 | 新規作成       | `/templates/new` へ遷移する                |
| 操作 | テンプレートクリック | `/templates/:id` へ遷移する                |

### テンプレート詳細 T-DETAIL

| 区分 | 項目／操作          | 説明                                              |
| -- | -------------- | ----------------------------------------------- |
| 表示 | テンプレート名        | テンプレートの題名を表示する                                  |
| 表示 | 項目リスト          | `label`、`order`、`isRequired` を一覧表示する            |
| 表示 | 作成者            | Ownerの `Account.name` を表示する                     |
| 操作 | 編集             | Ownerのみ表示する。`/templates/:templateId/edit` へ遷移する |
| 操作 | 削除             | Ownerのみ操作可能。使用中の場合は削除ボタンを無効化する                  |
| 操作 | このテンプレートでノート作成 | `/notes/new?templateId=:id` へ遷移する               |

### テンプレート新規作成 T-NEW

| 区分 | 項目／操作   | 説明                                    |
| -- | ------- | ------------------------------------- |
| 入力 | テンプレート名 | 必須。テンプレート名を入力する                       |
| 入力 | 項目追加    | `label`、`isRequired`、`order` を追加・編集する |
| 操作 | 項目の並べ替え | ドラッグ＆ドロップで順序を変更する                     |
| 操作 | 保存      | 作成後、`/templates/:id` へ遷移する            |
| 操作 | キャンセル   | `/templates` へ遷移する                    |

### テンプレート編集 T-EDIT

| 区分 | 項目／操作        | 説明                         |
| -- | ------------ | -------------------------- |
| 入力 | テンプレート名      | 既存の名称を編集する                 |
| 入力 | 項目リスト        | 既存のFieldを表示・編集する           |
| 操作 | 項目追加／削除／並べ替え | UI上で項目を操作する                |
| 操作 | 保存           | 更新後、`/templates/:id` へ遷移する |
| 操作 | 削除           | Ownerのみ操作可能。使用中の場合は削除できない  |
| 操作 | キャンセル        | `/templates/:id` へ戻る       |

* 項目リストで扱う値

  * `label`
  * `isRequired`
  * `order`

* 使用中テンプレートの編集ルール

  * 項目追加は可能とする。
  * 項目削除については要検討とする。
  * テンプレート自体の削除はできない。
  * 削除ボタンを非活性にし、注意文言を表示する。

### マイノート一覧 AC-ME

| 区分 | 項目／操作     | 説明                                 |
| -- | --------- | ---------------------------------- |
| 表示 | 自分のノートリスト | `ownerId == Account.id` のノートのみ表示する |
| 表示 | ステータス     | `Draft` または `Publish` を表示する        |
| 表示 | 更新日時      | 最終更新日を表示する                         |
| 操作 | 検索ボックス    | 自分のノート内でタイトルを検索する                  |
| 操作 | ノートクリック   | `/notes/:id` へ遷移する                 |
| 操作 | 新規作成      | `/notes/new` へ遷移する                 |
| 操作 | ステータスフィルタ | `Draft` または `Publish` で絞り込む        |

* ノートの編集・削除は、ノート詳細画面またはノート編集画面で行う。
