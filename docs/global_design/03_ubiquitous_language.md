# ミニNotion ユビキタス言語

## アカウント関連

| 用語                    | 定義                            |
| --------------------- | ----------------------------- |
| Guest（ゲスト）            | ログイン・登録していないユーザー              |
| Account（アカウント）        | 登録し、ログインしているユーザー。本人を指す     |
| OtherAccount（他アカウント） | 登録し、ログインしているユーザー。本人以外のユーザー |
| Owner（作成者）            | ノートやテンプレートの所有者。作成したユーザー    |
| Auth（認証）              | ユーザーの本人確認機能（Googleログイン）           |

## ノート（Note）関連

| 用語                | 定義                                           |
| ----------------- | -------------------------------------------- |
| Note（ノート）         | 設計メモ1件。テンプレートに従って記録する                     |
| NoteId（ノートID）     | ノートを一意に識別するためのID                             |
| Title（タイトル）       | ノートのタイトル。設計テーマなどを表す                       |
| Section（セクション）    | テンプレートで定義されたノート側の記入欄。Contentを持つ。例：Problem、原因、対策        |
| Content（本文）       | ユーザーが各セクションに入力する文字列。MVPではテキストのみ           |
| Status（ステータス）     | 公開（Publish）または下書き（Draft）。公開の場合、全ログインユーザーが閲覧可能 |
| UpdatedAt（更新日時）   | ノートが最後に更新された日時                               |
| CreatedAt（作成日時）   | ノートを初めて作成した日時                                |
| MyPage（マイページ）     | 自分が作成したノート一覧を見られる画面                          |
| NoteList（ノート一覧）   | ノートを一覧で表示する画面。検索・フィルタができる                 |
| NoteDetail（ノート詳細） | ノート1件を表示する画面。作成者や更新日時も表示される               |

## テンプレート（Template）関連

| 用語                              | 定義                                           |
| ------------------------------- | -------------------------------------------- |
| Template（テンプレート）                | Noteの雛形。どのような項目（セクション）があるかを定義する           |
| TemplateId（テンプレートID）            | テンプレートを一意に識別するためのID                          |
| TemplateField（テンプレート項目）         | テンプレート側の項目定義。例：Problem、原因、対策など         |
| FieldName（項目名）                  | 各テンプレート項目の名前（Label）                          |
| FieldOrder（順序）                  | 項目の並び順                                       |
| IsRequired（必須）                  | テンプレート項目が必須かどうかを表す設定                         |
| TemplateList（テンプレート一覧）          | すべてのテンプレートを表示する画面                            |
| TemplateDetail（テンプレート詳細）        | テンプレートの構造を表示する画面。項目名・順序・必須設定などを表示する       |
| TemplateSearch（テンプレート検索）        | テンプレートをタイトルで検索する機能                       |
| ApplyTemplate（テンプレート適用）         | ノート作成時にテンプレートを選択して使うこと                       |
| TemplateOwner（テンプレート作成者）        | テンプレートを作成したユーザー。編集・削除権限を持つ                |
| TemplateUsageCheck（利用中テンプレチェック） | そのテンプレートを使ったノートが存在するか確認する処理。使用中の場合は削除できない |

## 操作・機能関連

| 用語           | 定義                                                         |
| ------------ | ---------------------------------------------------------- |
| Search（検索）   | NoteまたはTemplateをタイトルで部分一致検索する機能。MVPではノートのタイトル、テンプレート名のみ |
| Filter（フィルタ） | ステータスで絞り込む機能。MVPではタグ機能は未実装                              |
| List（一覧表示）   | 複数のノートやテンプレートを一覧で表示する画面                                    |
| Edit（編集）     | 既存データ（ノート／テンプレート）を修正する操作                                   |
| Delete（削除）   | ノートやテンプレートを削除する操作。MVPでは物理削除                             |
| Publish（公開）  | ノートのステータスを「Publish（公開）」に変更する操作                             |
| Unpublish（下書きに戻す）  | ノートのステータスを「Draft（下書き）」に変更する操作                             |
| Draft（下書き）   | ノートを編集中の状態として保存するステータス                                     |
| Sort（並び替え）   | 一覧で更新日時順に表示する機能                                            |

## データ・技術関連（システム視点）

| 用語               | 定義                                  |
| ---------------- | ----------------------------------- |
| Database（データベース） | PostgreSQL（Neon）。正規化されたテーブル構造を持つ |
| Cloud Run        | サーバーレスでコンテナを実行する環境                  |
| Cloud Build      | サーバーレスCI/CDプラットフォーム                 |
| GitHub Actions   | CI/CDパイプライン。自動テスト、自動デプロイ         |
| Cloud Logging    | GCP環境のリアルタイムログ管理サービス                |
| OAuth2（オーオース2）   | Googleログインで使う認証の仕組み                 |
